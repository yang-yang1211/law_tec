# 法訊雷達

**法訊雷達**是以網頁為主的個人化法律資訊服務。使用者選擇關注身分與議題後，首頁會依相關程度與法律進度整理法訊；重要更新可透過 LINE 官方帳號通知，並能向有來源依據的聊天機器人詢問。

目前階段：**競賽提案與 MVP 規劃**。首頁原型中的法訊與 LINE 連結狀態皆為示意資料。

## 專案文件

- [計畫書草案](docs/計畫書草案.md)：競賽提案、產品構想、AI 使用方式、資料與風險控管、時程。
- [團隊分工與 GitHub 協作](docs/團隊分工與GitHub協作.md)：五人責任、交付項目、任務狀態與日常同步方式。
- [網頁首頁原型](prototype/index.html)：可直接用瀏覽器開啟的靜態示意版；資料與 LINE 連結狀態皆為示意，尚未連接 API。
- [競賽簡章](NextWave_AI法創黑客松_簡章.pdf)：競賽規則、時程與評分標準。

## 核心功能

1. 個人化法訊首頁與推薦理由。
2. 立法院議程、會議與法案進度整理。
3. 使用者將網站帳號與 LINE 帳號連結後，依關注議題接收通知。
4. 以官方資料為依據、附來源與日期的法律資訊問答。

## GitHub 工作方式

目前以 [GitHub Issues 任務列表](https://github.com/yang-yang1211/law_tec/issues)追蹤 P-01–P-10。Issue 內標明負責角色、交付物、截止日與驗收條件；成員帳號確認後再加上實際 assignee。PR 和日常同步規則見 [團隊分工與 GitHub 協作](docs/團隊分工與GitHub協作.md)。
