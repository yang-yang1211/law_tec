# 法訊雷達

**法訊雷達**是以網頁為主的個人化法律資訊服務。使用者選擇關注身分與議題後，首頁會依相關程度與法律進度整理法訊；重要更新可透過 LINE 官方帳號通知，並能向有來源依據的聊天機器人詢問。

## 線上入口

[法訊雷達網站](https://law-tec.yang20041211.workers.dev/)

目前階段：**競賽提案與 MVP 規劃**。自動收集與首頁投遞已有規格；原型尚未連接官方來源或 LINE API，畫面資料仍為示意資料。

## 核心功能

1. 個人化法訊首頁與推薦理由。
2. 立法院議程、會議與法案進度整理。
3. 使用者將網站帳號與 LINE 帳號連結後，依關注議題接收通知。
4. 以官方資料為依據、附來源與日期的法律資訊問答。

## 原型目前範圍

- 首頁可切換「為你推薦／我追蹤的／最新消息」、搜尋法訊並刷新推薦；每則卡片顯示推薦理由與資料來源欄位。
- 可切換立法院情報、問法訊、收藏、通知中心與個人設定等頁面。
- 關注標籤與收藏會保存在目前瀏覽器；LINE 連結按鈕只切換示意狀態。
- 法案、議程、通知及聊天回答都是介面示意資料，沒有連接立法院、法規資料庫或 LINE API，不應視為最新法律資訊。
